# Gerenciador de Tarefas

Projeto desenvolvido com Spring Boot para gerenciamento de tarefas.

## Funcionalidades

- Criar tarefas
- Listar tarefas
- Excluir tarefas
- Filtrar tarefas (Todas, Pendentes, Concluídas)
- Contador de tarefas

## Tecnologias utilizadas

- Java
- Spring Boot
- Spring Data JPA
- Thymeleaf
- H2 Database

## Como executar o projeto

1. Clonar o repositório

git clone https://github.com/starallma/gerenciador-tarefas-spring.git

2. Abrir o projeto no IntelliJ

3. Executar a classe:

GerenciadorTarefasApplication

4. Acessar no navegador:

http://localhost:8080/tarefas
